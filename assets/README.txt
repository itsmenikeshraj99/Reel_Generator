Put a Space Grotesk Bold .ttf file here named exactly:

    SpaceGrotesk-Bold.ttf

Free download: https://fonts.google.com/specimen/Space+Grotesk
(This is the same font used for headings on the portfolio site --
keeping the reel captions in the same font keeps everything looking
like it came from one person, not three different templates.)

If this file is missing, render.py falls back to a plain default
font so the pipeline still runs -- it just won't look as sharp.
